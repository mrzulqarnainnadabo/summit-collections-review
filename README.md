# The Summit Collections — Premium storefront review

A mobile-first editorial storefront prototype for The Summit Collections, Abuja.

## Design direction
- Warm paper, ink and restrained wine/gold accents drawn from the brand's boutique presentation.
- Large product photography and editorial typography; the garments remain the visual focus.
- Quiet entrance and scroll-reveal motion, with native scrolling and reduced-motion support.
- Responsive product discovery with collection filters, search, product detail, bag and WhatsApp-assisted enquiry.

## Catalogue source
Product imagery is stored at the repository root and referenced by its original filename. The initial catalogue was transcribed from the supplied Instagram screenshot review; product names are descriptive labels, not confirmed official product names.

Important source limitations are preserved:
- IMG_3977 is a profile overview, not a product.
- IMG_3982 is an alternate view of the black floral abaya represented by IMG_3981.
- IMG_3993 is a group photograph, not an individually purchasable listing.
- Prices/sizes not visible in the source are shown as enquiry-only.
- Products marked sold or sizes marked unavailable are not represented as confirmed live stock.
- All prices and size availability require confirmation by the store before payment.

## Commerce boundary
This is a front-end catalogue and WhatsApp-assisted ordering experience. It does not process payments, maintain inventory, or provide a staff admin dashboard. The store must confirm stock, size, final amount and delivery directly with the customer.

## Local preview
Open `index.html` in a static web server. No build step or package install is required.
